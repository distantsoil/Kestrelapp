AppImage runtime (type2-runtime)

The Kestrel AppImage embeds the AppImage type 2 runtime, the small program at the start of every
AppImage that mounts the payload with FUSE (or extracts it when FUSE is absent) and starts the app.
It is vendored unmodified as packaging/linux/runtime-x86_64.

  Project:  https://github.com/AppImage/type2-runtime
  Built:    the `continuous` release asset runtime-x86_64, upstream commit fedfad5
  SHA-256:  617aa77314d57c8b8e4fae9c3f0b35af7b30d5529cb69e98f64f92510ed98a46
  Size:     944,632 bytes
  License:  MIT (the project's own code; the text follows)

The runtime is a statically linked musl binary. Upstream's src/runtime/Makefile links it against
squashfuse, zstd, zlib, libfuse3 and mimalloc, each distributed under its own license. Their source
and license texts are in the upstream repository at the commit above and in the projects named. The
exact source of this binary can be rebuilt from that commit (see BUILD.md upstream).
