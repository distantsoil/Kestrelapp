Backup

Take a backup before a reinstall, a machine move, or any experiment with the database. Restore is on Settings under the LAN & backup tab.

Download a backup

What it contains

  • The database kestrel.db, as one consistent copy: every opportunity, evaluation, pursuit, story, label, and document master and variant.
  • Every *.yml under {{ config_dir }}: settings, filters, sources, and your profile.
  • Generated PDFs: resumes and capability statements, and interview prep packs.

What it never contains

  • Your saved keys: no API key, no shared LAN secret, no online-model key. Keys are re-entered in Settings after a reinstall, by design.
  • The LAN shared secret is taken out of the database copy before it is zipped. Restoring keeps the secret this computer already has, so on a different computer, set up LAN pairing again on Settings, LAN & backup tab.
  • Logs, the learned ranking, the computer check, and the downloaded AI models. Open Setup to rebuild the models.

Profile only

The export is profile.yml alone. Document masters and variants live in the database and travel in the full backup; there is no separate masters export.

Import a profile

The file is parsed and loaded for at least one track before it replaces anything. The previous file is kept at {{ profile_bak }}. Your saved keys are never touched.

Restore

Restore from a backup zip on Settings, LAN & backup tab, or run kestrel restore <file.zip>. The archive is validated in full before anything is touched and the current database is copied aside first, so a bad restore is always reversible. Restart Kestrel afterward.
