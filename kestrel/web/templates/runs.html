Searching

Every source that is on is checked once. A site that asks Kestrel to wait is tried again next run.

Your rules

Roles your rules rule out, like the wrong place or a title you never want, are set aside. They stay in Pipeline, marked as set aside.

Quick screen

A small, fast model reads each role and keeps the plausible ones. When it is not sure, it keeps the role, so nothing good is thrown away.

Rating

The main model scores each kept role against your profile. This is the slow step, about 10 to 30 seconds a role on most computers.

Deeper read

Only on a role you pick, from its page. If it uses an online model, Kestrel shows what it will send and asks first.

{% endcall %} {% call ui.flyout('rn-pause-fly', 'Pause, Stop, and picking up', help_href='/help') %}

Pause

Holds the run between steps. Use it when you need the computer for something else. Resume carries on from the same role.

Stop

Ends the run. Everything finished so far is saved. The roles it did not reach wait, and Resume or Run now picks them up.

Quitting Kestrel or a power cut

Works the same way. Each step is saved as it finishes, so the next start carries on from there.

When to use which

Pause for a short break. Stop if the run is using the wrong settings, then start a new one with This run only.

{% endcall %} {% call ui.flyout('rn-fail-fly', 'When something fails', help_href='/help') %}

Partial

What it means: a site asked Kestrel to slow down. The rest of the run finished. What to do: nothing. That source is tried again next run. If one source is Partial every day, check it on Sources.

Needs another try

What it means: the AI gave an answer Kestrel could not read, twice, for one role. What to do: press Try again. If the same model keeps failing, pick another one or an online model. The role stays in Pipeline meanwhile.

Did not run

What it means: Kestrel could not reach the AI at all, for example the model app was closed. What to do: open Models and run the check. Nothing is lost; the run starts again once the AI is back.
