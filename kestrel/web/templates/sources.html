What happens on a check

Kestrel asks the source for its current list, keeps the postings it has not seen, and sends them to Pipeline to be scored. Postings it already has are skipped, even if they show up on several boards.

How often

Each source has its own schedule. Open Details and change How often to daily, weekly or more often.

How Kestrel stays polite

It follows each site’s robots.txt, waits between requests and names itself in every request. If a site asks it to wait, it stops there and tries again next check. That shows as Slowed down, and the rest of the run carries on.

Check now

Details has Check now for one source, and the toolbar has Check all now. Use them after you fix an address.

From your profile

Kestrel rebuilds these every time you save your profile, from your target titles and places, and also searches close variants of each title. Edit one and it becomes your own: it stops following your profile.

Found in results

When a search result links to a company’s own job board, on a hiring system Kestrel can read, Kestrel adds that board and checks it daily. At most {{ found_cap }} per track. Turn one off and it stays off: Kestrel never adds it again.

Suggested

Suggestions come from companies where you shortlisted or applied. Dismiss one and Kestrel stops suggesting it. Add one and it is marked Suggested.

Built in and added by you

Built-in sources give a new install somewhere to start. You can turn them off. Anything you add yourself, by link or by name, you can edit or remove.

Companies to watch

Pick companies you would like to work with. New leadership, an acquisition or a new site often means they need outside help.

A good search

One kind of work per search, like “contract reporting analyst”. A long list of terms in one search returns noise.

Public bids

Add a bid search for each kind of work, with the industry codes that fit it. SAM.gov needs your own free key, under Sources that need your own key.

{% else %}

Finding a careers page

Search the web for the company name plus “careers”, open any job, and copy the address. Or use Company by name and let Kestrel look.

A good search

“Operations Analyst” in Austin works better than “manager” anywhere. Add a second search for a second title rather than one long list.

Which boards

Indeed and Glassdoor find the most. ZipRecruiter and Google Jobs are limited today, and Kestrel says why before you add them.

{% endif %} {% endcall %} {% call ui.flyout('src-limits-fly', 'When a source does not work', help_href='/help#sources') %}

LinkedIn

How to tell: it is not offered in Add a source. What to do: open the posting on LinkedIn, copy the text, and use Add a role I found elsewhere on {{ 'Leads' if track == 'consulting' else 'Applications' }}. Kestrel scores it like any other role.

A site that needs you to sign in

How to tell: Check says Kestrel does not read that kind of page. What to do: copy the posting text, or save the posting as a PDF, and add it on {{ 'Leads' if track == 'consulting' else 'Applications' }}.

A board that always finds 0

How to tell: the row shows 0 open on every check. ZipRecruiter and Google Jobs do this today. What to do: turn it off and use Indeed and Glassdoor, or add the companies you care about directly.

A search near 1,000

How to tell: the row shows close to 1,000 open. Boards stop there, so roles are missed. What to do: split it. For example, run “Operations Analyst” as three searches, for Austin, Dallas and Houston, instead of one for all of Texas.
