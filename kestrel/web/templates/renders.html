The short version

Kestrel looks at this role and picks which of your own wordings to use for each line. You check each pick, swap any you like, then download the PDF.

The three parts

  • Left: each line with its pick and the reason.
  • Middle: the page as it will print.
  • Right: what the role asks for and what your documents cover.

Good to know

Kestrel never applies or sends anything for you.

{% endcall %} {% call ui.flyout('tl-how-fly', 'How Kestrel picked', help_href='/help') %}

Why your own words

Every line in the {{ kind }} is text you wrote in Profile, printed exactly as written. Kestrel only decides which of your wordings fits this role best.

If a pick fails a check

If Kestrel names a wording you never wrote, the line is marked "Needs your pick" and your first wording shows until you choose. Nothing is ever filled in for you.

Pick again

Asks Kestrel to choose again. Lines you changed yourself stay as you set them.

{% endcall %} {% call ui.flyout('tl-change-fly', 'Change a line', help_href='/help') %}

Swapping

A swap shows in the preview at once and is marked "Your choice". Kestrel learns from your swaps over time.

Need a new wording

Add it in Profile, Documents. It appears here as another choice, so every line stays your own.

{% endcall %} {% call ui.flyout('tl-fit-fly', 'Fit the page', help_href='/help') %}

The limit

The page limit is set in Settings. If the {{ kind }} runs over, the notice lists every optional line that is showing, in order. Leave out the ones you can spare.

Zoom

Use the minus and plus buttons above the preview to read small text, or Enlarge for the full page.

{% endcall %} {% call ui.flyout('tl-apply-fly', 'Before you apply', help_href='/help') %}

What each button does

Download PDF saves a file to your computer. Use for this {{ w.app if w else 'application' }} attaches this version to the role in {{ w.apps if w else 'Applications' }} so you can find it later. Neither sends anything.

Privacy

Hide my current employer swaps in your neutral label. The PDF holds no company names in its file details.
