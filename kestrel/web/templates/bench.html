{% call ui.flyout('ck-how-fly', 'How Model check works', help_href='/help') %}

One button

Check my models tests Quick screen and Rating against other models that fit this computer, scoring them against an answer key: your own rated roles once you press Use my ratings as the answer key, otherwise a shipped set of example roles. Deeper read is optional.

In the background

The check keeps running if you leave this page, and picks up where it stopped after a restart. Cancel stops it.

What it is not

Model check compares models on your own ratings so you can choose which model runs each step. It does not review your resume; that lives on Profile > Documents.

What it recommends

A change only when a model is clearly better for you. Kestrel prefers a model on this computer unless an online one is at least 5 points better, and always asks before anything goes online.

{% endcall %} {% call ui.flyout('ck-why-fly', 'Why this exists', help_href='/help') %}

Models change

Better models appear all the time, and your ratings teach Kestrel more about what you like. A check tells you whether to switch.

When to check

After you add a model, after every 30 new ratings, and after a model update. Kestrel suggests it on Today.

{% endcall %} {% call ui.flyout('ck-measure-fly', 'What it measures', help_href='/help') %}

Matching the answer key

For each role in the answer key, Kestrel asks the model the same question and counts how often it reaches the key's verdict. Quick screen is judged on keep or skip; Rating on the verdict. The two are never compared with each other.

Roles in the key

Every figure shows how many roles in the answer key it rests on. Under five, it says there is too little to judge.

{% endcall %} {% call ui.flyout('ck-time-fly', 'How long it takes', help_href='/help') %}

Time

It depends on your computer and the number of models tried. Free online models can be much slower than paid ones.

Cost

Models on this computer are free. An online model uses your credit, and only when you tick Include online models.
