Speed: roles scored at once

Choose 1 to 16 requests at once for each step. Start low: higher values use more memory and can slow your computer. Kestrel finishes one step's queue before starting the next, even when they share a model.

For local models, set OLLAMA_NUM_PARALLEL to at least {{ sp_parallel }} in Ollama's environment, then restart Ollama. This includes the similar-role matching step. A lower value can make requests wait in line. Kestrel cannot check the environment of a separate Ollama process.

Set OLLAMA_KEEP_ALIVE=2h in Ollama's environment to avoid reloading models between steps. Online providers have their own request limits.
