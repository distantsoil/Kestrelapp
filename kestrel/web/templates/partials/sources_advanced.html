SAM.gov consulting

US federal contract opportunities: requests for proposals for IT services posted by government agencies. Useful only if you take consulting work. It needs a free API key.

How to get a SAM.gov API key
  1. Go to sam.gov and sign in. SAM.gov uses Login.gov; create a free Login.gov account if you do not have one.
  2. Open your profile menu and choose Account Details (on some screens it is under Workspace).
  3. Find Public API Key, request a key, and copy it. It may ask you to confirm with your Login.gov sign-in.
  4. Paste the key below and save. Kestrel keeps it in its own key file on this computer and sends it only to SAM.gov.
