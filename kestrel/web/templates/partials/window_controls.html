{# Window controls at the top of the sidebar (D-UI-88, SPEC-INTERFACES 1.7). Rendered only while the desktop shell runs, and hidden until the page finds the desktop window's JS API (window.pywebview), so a browser tab on the same server never shows them. Windows and Linux: minimize, maximize or restore and close, drawn here, close red on hover. macOS: the real traffic lights sit over this row (a transparent title bar), so the row is only a spacer. Close obeys close-to-tray exactly as the window's own close does. The empty part of the row is the drag region; a double click toggles maximize. The edge handles below resize the frameless window on Windows and Linux; they live in partials/window_edges.html, outside .k-win, whose container query would otherwise pin them to the page instead of the window. Behavior: static/js/kestrel-ui.js (KUI.frame). #}
