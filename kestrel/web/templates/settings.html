LAN access

What is this? Optional. It lets you open Kestrel from another device on your home network, a phone or tablet on the same Wi-Fi, to read Today, review the pipeline or check a pursuit away from the desk. The app, the models and the data stay on this machine. If you only ever use Kestrel here, leave it off. More in Help.

Kestrel listens on this machine only until you turn on server.bind_all. That is set in settings.yml or as KESTREL_SERVER__BIND_ALL=true, not on this page, and it takes a restart. With it on, Kestrel also answers on your local network, and every request to the web interface from another device must carry the shared secret below, as the X-Kestrel-Key header or as a cookie set by scanning the code once. Requests from this machine never need it.

Read this before you turn it on. This is one shared password for the whole application. There are no accounts, no per-device access, and no way to see who did what. Anyone who has the secret, or who is on a network where they can read unencrypted traffic, can do everything you can do: read every opportunity, every document, and your profile. Traffic is plain HTTP and is not encrypted. Use this on a home network or a VPN you control. Do not use it on shared, public, or office Wi-Fi, and do not forward the port through a router. Do not put a local proxy or port forwarder in front of Kestrel either: that makes every request look like it came from this machine, which switches the secret off entirely.

What else the secret gates. With bind_all on, the MCP server (if enabled) listens on its own port and requires the same secret as the X-Kestrel-Key header from any device that is not this machine; there is no separate MCP password. The browser extension must carry the secret too, even on this machine, so paste it into the extension's options page. Two cautions: the join link contains the secret, so it lands in that phone's browser history, and the secret is displayed on this page in clear text.

Rotating takes effect immediately and locks out any device using the old one. That is the only way to revoke access.

Your data lives at {{ data_dir }}. Back up with kestrel backup (zips the database, config, and generated documents; never your API keys or the LAN shared secret).
