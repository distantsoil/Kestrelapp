Help

What Kestrel does

Kestrel is a free job search app for any job seeker. It runs on your own computer (Windows, macOS or Linux) and you are not the product. It finds openings from public job boards and company hiring pages, checks each one against what you want, and shows the ones worth a look with the reasons. It tailors your own resume text to each role, tracks every application to its outcome, and helps you prepare for interviews and offers. It learns from the decisions you record. If you do consulting or contract work, there is an optional second track for that, off by default.

The AI runs on your computer by default. You can instead use an online model with your own key (OpenRouter, OpenModel, Anthropic, OpenAI or any OpenAI-compatible service), and Kestrel asks before anything goes online. It never applies, emails or messages anyone for you.

LinkedIn

Kestrel does not search LinkedIn; LinkedIn does not allow automated access. You can paste a LinkedIn posting by hand.

RemoteRocketship (optional, paid)

What it is. An optional source for people who already pay for RemoteRocketship with API access. Kestrel stays free; this source needs your own RemoteRocketship subscription and is off until you add it.

How to turn it on. Open Sources and find the RemoteRocketship card. Paste your key, choose Save key, then Turn on. Run now checks right away. The key is kept in Kestrel's private key file on this computer, never in the source and never shown again (only its last four characters). Turn off pauses the source.

What Kestrel keeps. Only the link to each employer's own posting. The posting is then read from the employer's site, or from the company's job board when it is one Kestrel knows. Nothing from RemoteRocketship is stored: no titles, descriptions or company details, and not the reply itself, which fits their terms limit of 24 hours.

Daily limits. RemoteRocketship allows 500 requests or 3,000 jobs per UTC day. Kestrel uses a few requests per scan (two by default, 50 jobs each). A link that cannot be read from the employer is skipped and counted in the run.

If something goes wrong. "Did not receive an API key" or "did not accept the API key": paste the key again in the RemoteRocketship card. "Needs an active paid subscription": your plan does not include API access. "Daily limit was reached": wait until 00:00 UTC. The run is marked partial, and it does not count as a failure of the source. If the limit hits after the first page, the links from the earlier pages are still used; if it hits on the first page, the run finds nothing and the next scan tries again.

Filters. With no filters set on the source, Kestrel asks for your target titles and onsite metros from your profile. Filters you write on the source replace them.

What never happens

Kestrel never submits an application, never sends an email or a message, never clicks apply, never fills in or submits an ATS form, and never automates any social platform. It drafts, recommends, and hands over. Every send is yours. This boundary is deliberate and it is not configurable.

It reads only public pages and public filings, respects robots.txt, identifies itself with a descriptive User-Agent, rate-limits every source, and never logs in anywhere.

What leaves this machine

Nothing, by default. The AI runs on your own computer. Two opt-in paths send data out, both with your own key and both stated in full before you confirm: a deeper read you request for one role, and Hosted mode, which sends your scoring to an online model you choose (OpenRouter, OpenModel, Anthropic, OpenAI or any OpenAI-compatible service). Both are on Settings, Hosted (BYOK) tab.

The source scans themselves make ordinary public requests to job boards and filings; the only thing they carry is the search you configured.

Backups and reinstalls

The Backup page downloads one zip with the database, the YAML config and the generated PDFs, exports or imports your profile on its own, and explains what is never included (every key you saved). Restore is on Settings, LAN & backup tab.

After a reinstall: install, open Setup in the app to rebuild the models, restore the backup, and re-enter any keys in Settings. The LAN shared secret is not in the backup either, so on a different computer, set up LAN pairing again.

Kestrel from another device

Optional, and off by default. Kestrel is a web page served by the desktop app, so it can also be opened from a phone, tablet or laptop on the same home network: read Today, review the pipeline, check an application or your interview prep away from the desk. Nothing moves: the models, the database and the documents stay on this machine, which has to be running (in the window or the tray).

Turning it on is a switch on Settings, LAN & backup tab. You generate one shared secret, tick that you read what it does and does not protect, and turn the switch on; it takes effect after you quit and reopen Kestrel. Then you share the secret with each device. If you only use Kestrel at this computer, leave it off.

Check for updates

Kestrel checks kestrelapp.co once a day for a newer version. Nothing about you is sent. Kestrel never downloads or installs anything; you choose if and when to update. You can turn the daily check off under Settings.

The version, the source repository, how to support the project, and the diagnostics download for reporting a problem are on About.
