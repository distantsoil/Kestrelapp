# Today

Start with **Top matches today**, then work through **Decisions waiting** and **Applications needing action**. Use the status strip to start or monitor a scan and open run history, today's results, or model settings. Today follows the selected Employment or Consulting track; Kestrel records your choices but never applies or contacts anyone for you.

When both tracks are enabled, use the sidebar tabs to switch between Employment and Consulting.

## Start or check a scan

The three-part status strip summarizes the search:

- **Last run** shows the latest run's time and outcome. When a run finished without a problem and another run is scheduled, this segment alternates with **Next run**. A problem keeps the last-run details visible. Select the segment to open [Runs](runs.md).
- **New roles found** shows the count and scoring progress, including rated, failed, and waiting roles. Select it to open today's results in [Pipeline](pipeline.md).
- **Model** names the local, online, or combined model setup in use. Select it to open [Models](models.md).

Choose **Run now** to open the model chooser. After you choose the usual models or a model for this scan, Kestrel starts every enabled search. While a scan is running, the control changes to **Cancel scan**. This cancels searches that have not started; the source currently being checked finishes.

When the worker is processing roles, choose **Pause** to let already-running tasks finish and stop new tasks from starting. Choose **Resume** to continue. A paused run stays visible in the status strip.

The first-run strip says **No runs yet** and prompts you to run the first search. An active run shows its current search or scoring progress. A completed run shows its time and outcome; an interrupted or failed run shows a warning. If roles still need a scoring retry, the note below the strip shows the count and a **Review** link to [Needs another try](needs-another-try.md).

If setup is incomplete, **Finish setup** opens the remaining setup steps. On the first Today page, **Take a short tour of Today** opens a walkthrough. Use **Next**, **Back**, **Skip tour**, or **Close** to move through or leave it.

## Review today's matches

**Top matches today** shows new roles ranked by fit. Its subtitle reports new roles found today, **All caught up** when today's results have already been actioned, or **Nothing found yet today** when there are no results. A card that is still being scored says **Being scored**; its full review and details appear when scoring finishes.

Each scored card can show the fit label and score, location, pay, matching skills, and a short AI-written explanation. Estimated pay is marked **est.** Select **Review role** to open a read-only role summary. Choose **Save for later** to bookmark a role without deciding on it, or **Shortlist** to add it to Applications. In Consulting, these buttons are **Review**, **Save for later**, and **Add to leads**. The confirmation toast offers **Undo** for supported actions.

Use **Previous matches** and **Next matches**, the page dots, the left and right arrow keys, or drag the cards to move through the carousel. **View all matches** opens today's results in [Pipeline](pipeline.md). When every card is actioned, the empty card offers **Run a scan** and **Open Pipeline**. With no matches yet, it offers **Run a scan**.

## Clear decisions and due work

**Decisions waiting** lists items that still need a choice. In Employment, choose **Shortlist** or **Ignore** for a new role. For a shortlisted role, choose **Tailor resume** or **I applied**. **I applied** records your action in [Applications](applications.md); it does not submit an application.

**Applications needing action** lists follow-ups and interviews coming up. Depending on the item, choose **Prepare**, **Follow up again**, or **Open**. **Follow up again** records another follow-up and moves the next follow-up date a week out. **View all** opens [Applications](applications.md). If no items are due, the panel says **Nothing is due this week**.

If you turn a track off, Today still shows its open work under the due-work panel, with a link to that track's board. Turning off a track does not hide applications or follow-ups that still need attention.

## Consulting track

Consulting changes the page's role wording to opportunities. Top matches can include postings, RFPs, and referrals. The page adds **New signals** when there are new public trigger events. A signal suggests that an organization may need outside help; it is not a job posting. Choose **Research**, **Add to leads**, or **Not relevant** for a signal.

In **Decisions waiting**, choose **Add to leads** or **Ignore** for an undecided opportunity. For a lead that still needs contact, **Draft outreach** is disabled and **I reached out** records that you made contact. Kestrel does not draft or send outreach from Today. **Leads needing action** lists proposals, follow-ups, and calls coming up, with the same **Prepare**, **Follow up again**, or **Open** actions when they apply.
